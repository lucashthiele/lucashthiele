## 🚀 What I'm working on

### 🥗 Prato em Dia
A platform that connects **nutritionists and patients**: the nutritionist publishes a meal prescription on the web portal, and the patient turns it into a weekly plan and a daily food log on the mobile app.

| Project | Stack | Highlights |
|---|---|---|
| [**prato-em-dia-server**](https://github.com/lucashthiele/prato-em-dia-server) | Java 25 · Spring Boot 4 · PostgreSQL · Flyway | JWT + refresh tokens, versioned prescriptions, scheduled weekly plan generation, TACO/TBCA food table import, OpenAPI, tests with Testcontainers and ArchUnit |
| [**prato-em-dia-portal-web**](https://github.com/lucashthiele/prato-em-dia-portal-web) | React 19 · TypeScript · Vite · TanStack Query | Typed API client generated from OpenAPI, custom design system, Vitest + Testing Library + MSW |
| [**prato-em-dia-mobile**](https://github.com/lucashthiele/prato-em-dia-mobile) | Flutter · BLoC/Cubit · Dio | Daily plan, weekly planning, food diary, food catalog and secure session handling |
